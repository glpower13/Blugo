# 11 — Ideen-Parkplatz (nicht im MVP-Kern)

Sammelstelle für Features, die reizvoll, aber nicht MVP-kritisch sind. Nichts hier wird ohne ausdrückliche Priorisierung gebaut.

- **Songs als Input (Birkenbihl-Lieder-Ansatz):** schwedische Lieder dekodieren und als Comprehensible Input nutzen (Melodie verankert Chunks, Prosodie, Wiederholung). Mögliche Eigenerzeugung schwedischer Songs (z. B. via Suno) → Auto-Dekodierung → Input-Segment. Einzigartiges, gut zum Nutzer passendes Feature.
- **Shadowing/Aussprache-Coach** (ASR-basiert), sobald Rezeption stabil ist.
- **Konversationstutor** (adaptiver Dialog) als späte Stufe, nicht als Keil.
- **Kontext-Themenwelten** (Reise, Arbeit, Alltag) für Interleaving mit Bedeutung.
- **Export/„lebendes Gedächtnis" als Visualisierung** über lange Zeiträume.
- **Mehrsprachigkeit** (weitere Zielsprachen) nach bewiesenem Schwedisch-Loop.
