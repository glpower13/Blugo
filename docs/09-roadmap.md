## M1 — schlankes MVP (der Beweis)
Ziel: den Lern-Loop an *einem echten Lerner* wirksam zeigen.
- **Ein** Level, **~20 handgeprüfte** KI-generierte schwedische Segmente (Audio + Dekodierung).
- Vollständiger Comprehension-Loop (Begegnung → Abruf → Logging).
- Memory-Engine minimal: echtes Spacing + Wartung fälliger Chunks.
- Simple, ehrliche Fortschrittsanzeige (aktive/stabile Chunks, Verständnis-Abdeckung).
- Web zuerst, lokale Speicherung.
- **Erfolgskriterium:** Chunks bleiben nach mehrwöchiger Pause messbar stabiler als bei reinem Wiederholen ohne Spacing/Wartung.
